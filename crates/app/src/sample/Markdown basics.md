# Markdown basics

Notes are written in Markdown. The markup hides itself while you are not editing that line; put the cursor on a line to see it again.

## Text

**Bold**, *italic*, ~~struck through~~, ==highlighted== and `code`.

## Lists and tasks

- A list item
- Another one
    - Indented with Tab

- [ ] A task to do
- [x] A finished task (Ctrl+L toggles it)

## Quotes and callouts

> A plain quote.

> [!note] A callout
> Callouts draw attention to something.
