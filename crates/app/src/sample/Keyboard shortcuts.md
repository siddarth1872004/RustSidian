# Keyboard shortcuts

| Keys | What it does |
| --- | --- |
| Ctrl+N | Create a new note |
| Ctrl+O | Go to a file (quick switcher) |
| Ctrl+P | Command palette: every command, searchable |
| Ctrl+Shift+F | Search in all notes |
| Ctrl+E | Switch between editing and reading view |
| Ctrl+S | Save now (notes also save by themselves) |
| Ctrl+W | Close the current tab |
| Ctrl+Shift+T | Reopen the tab you just closed |
| Ctrl+Tab | Next tab |
| Ctrl+G | Open the graph view |
| Ctrl+B / Ctrl+I | Bold / italic |
| Ctrl+, | Settings |
| Ctrl+\ | Show or hide the left sidebar |

You can change any of these in **Settings → Hotkeys**.
