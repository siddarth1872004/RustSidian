# Links and the graph

Type two square brackets to link to another note: [[Welcome]]. Linking is what turns a pile of notes into something you can explore.

- A link to a note that does not exist yet, like [[An idea for later]], creates it when you follow it.
- Add text after a bar to change what the link shows: [[Markdown basics|how to format notes]].
- Tags such as #start group notes without linking them.

The right sidebar (the icon at the top right of a note) lists a note's outline and its **backlinks**: every note that links here.

Press **Ctrl+G** for the graph view. Each dot is a note and each line is a link.
